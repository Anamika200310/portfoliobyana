# Anamika — My Little Universe

Open `index.html` in your browser. All animations are built with CSS and vanilla JavaScript. To deploy, upload the files to GitHub Pages, Netlify or Vercel. Keep `AnamikaKS_CV.pdf` next to `index.html` so the CV button works.

The emoji avatar is a placeholder and can be replaced with your own illustration or photo. Hobby labels are editable in `index.html`. The design uses animated stars, sticky project cards, scrolling ticker and scroll-reveal effects, with reduced-motion accessibility support.
